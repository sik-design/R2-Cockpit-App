🔒 키움증권 API 보안 금고 ?

현재 R2 시스템은 국내에서 가장 안정적인 자동매매 환경을 제공하는 '키움증권' 전용으로 설계되어 있습니다.

증권사들마다 통신 언어와 기준이 모두 달라서 하나로 통일하여 완벽성을 높였습니다. 추후 업데이트를 통해 KB증권, 한국투자증권 등 다른 증권사들도 차례대로 선택하실 수 있도록 기능이 추가될 예정입니다.
키움증권 앱(영웅문)이나 홈페이지에서 확인하실 수 있는 8자리 숫자 계좌번호입니다.

예를 들어 계좌번호가 12345678 이라면 하이픈(-)이나 빈칸 없이 숫자만 정확하게 적어주세요. 이 번호가 틀리면 매수 주문이 들어가지 않습니다.
키움증권 홈페이지(Open API)에서 대표님께서 직접 발급받으신 영문과 숫자가 섞인 긴 키입니다.

로봇이 대표님을 대신해서 주문을 넣으려면 '내가 이 계좌의 주인으로부터 권한을 받았다'는 신분증이 필요한데, 그것이 바로 이 앱 키입니다.
위의 앱 키와 짝을 이루는 아주 중요한 비밀번호(시크릿 키)입니다.

걱정하지 마세요. 여기에 입력하시는 정보는 외부 서버로 단 1바이트도 빠져나가지 않으며, 오직 대표님이 지금 들고 계신 스마트폰 안드로이드 기기 내부의 특수 보안 금고에만 철저하게 암호화되어 안전하게 보관됩니다.
